# 실기기 검증 절차

1. APK를 Galaxy에 설치합니다.
2. 앱을 열고 Bluetooth/Nearby devices와 알림 권한을 허용합니다.
3. 케이스를 열고 5~10초 기다립니다. 홈 화면에 모델과 L/R/Case 상태가 나타나는지 확인합니다.
4. 설정에서 오버레이 권한을 허용한 뒤 앱을 백그라운드로 보내고 케이스를 다시 열어 팝업을 확인합니다.
5. 위젯을 추가한 뒤 케이스를 열거나 이어버드를 꺼내 위젯이 갱신되는지 확인합니다.
6. 배터리가 나타나지 않으면 케이스에 이어버드 하나 이상을 넣고 케이스를 연 상태에서 다시 5~10초 기다립니다. Apple BLE 광고를 보내지 않는 호환 기기는 배터리를 제공할 수 없습니다.

확인되지 않은 값은 --로 남으며 임의의 퍼센트로 대체하지 않습니다.
